## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 MainWindow's Grid has three RowDefinitions and two ColumnDefinitions
- [ ] #2 Row 0 has a TextBlock reading "Id" in Column 0 and an empty (data-bound) TextBlock in Column 1; Row 1 has a TextBlock reading "Name" in Column 0 and an empty (data-bound) TextBlock in Column 1
- [ ] #3 Row 2 contains a StackPanel spanning both columns and horizontally centered, stacking a TextBox and a Button whose content reads "Search"
- [ ] #4 A ViewModels folder is added containing PokedexViewModel, which derives from ObservableObject (or uses [ObservableObject]/partial class per CommunityToolkit.Mvvm conventions)
- [ ] #5 PokedexViewModel exposes two observable properties for the Pokemon's Name and Id, bound to the Column 1 TextBlocks
- [ ] #6 PokedexViewModel exposes a [RelayCommand] bound to the Search button that accepts the TextBox's text, determines whether it is numeric (id) or textual (name), calls the corresponding PokeApiService/PokedexEndpoint GetEntryAsync overload, and updates the observable Name/Id properties from the result
- [ ] #7 PokedexViewModel receives PokeApiService (or IPokeApiService) via constructor injection
- [ ] #8 App.xaml.cs registers PokedexViewModel in the DI container and resolves MainWindow (or its DataContext) through the IServiceProvider so the injected ViewModel is used at startup
- [ ] #9 Solution builds and MainWindow launches without runtime errors
