## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Model the sprites object from https://pokeapi.co/api/v2/pokemon/magnemite, excluding only the top-level sprites.versions sub-object handled by PDX-001.03.09. Create OfficialArtwork, Home, Showdown, DreamWorld, OtherSprites, and Sprites as separate model files. OfficialArtwork has nullable FrontDefault and FrontShiny plus a Versions property for its own nested versions object. Model the live official-artwork.versions structure with OfficialArtworkVersions, OfficialArtworkGeneration1, OfficialArtworkGeneration2, and a shared OfficialArtworkVersion value class: map generation-i to RedAndBlue and RedAndGreen, generation-ii to GoldAndSilver, and each pair's nullable front_default. Home has nullable FrontDefault, FrontFemale, FrontShiny, and FrontShinyFemale. Showdown and DreamWorld have nullable string fields matching the live payload. OtherSprites has Home, Showdown, DreamWorld, and OfficialArtwork. Sprites has nullable direct back_default, back_female, back_shiny, back_shiny_female, front_default, front_female, front_shiny, and front_shiny_female fields plus Other; leave top-level Versions for PDX-001.03.09.
