## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core, create a Models folder and add the reusable classes that represent the recurring {"name": "...", "url": "..."} reference objects found throughout the pokemon/{name-or-id} payload (see https://pokeapi.co/api/v2/pokemon/magnemite). Create Form.cs the same way as the other classes here.
