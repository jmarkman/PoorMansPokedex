## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In MainWindow.xaml, add three RowDefinitions and two ColumnDefinitions to the root Grid. Add four TextBlocks in the first two rows: Column 0 shows static labels "Id" and "Name" (one per row), and Column 1 holds two empty TextBlocks (one per row) that will be bound to the Id and Name values. In the third row, add a StackPanel spanning/centered across both columns containing a TextBox (for the search input) followed by a Button labeled "Search", stacked vertically and centered. Add a ViewModels folder (already present but empty) and create PokedexViewModel using CommunityToolkit.Mvvm: use [ObservableProperty] for two observable properties, Id and Name, and an [RelayCommand] async command that calls PokeApiService.PokedexEndpoint.GetEntryAsync using either the numeric id or textual name typed into the search TextBox (try parsing the input as an int first, falling back to treating it as a name), then updates Id and Name from the resulting PokedexEntry. Wire PokedexViewModel as MainWindows DataContext via the DI container from the previous subtask, and bind the Column 1 TextBlocks, the search TextBox, and the Search button to the ViewModel. Depends on the DI setup and on PokedexEndpoint being available through PokeApiService.
<!-- SECTION:DESCRIPTION:END -->
