## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core, create an Endpoints folder containing a PokedexEndpoint class and its IPokedexEndpoint interface (separate files). IPokedexEndpoint declares two async method signatures, GetEntryAsync(string name) and GetEntryAsync(int id), each returning Task<PokedexEntry>. PokedexEndpoint implements the interface; its constructor accepts the caching HttpClient wrapper from Feature 1 item 2, and each GetEntryAsync overload builds the appropriate request path (pokemon/{name} or pokemon/{id}), sends it through the wrapper, and deserializes the resulting JSON into a PokedexEntry using System.Text.Json. Once PokedexEndpoint is complete, add a read-only getter property to PokeApiService that exposes it; PokeApiService constructs the HttpClient wrapper and the PokedexEndpoint from the HttpClient it was given, and assigns the PokedexEndpoint to this property in its constructor. Depends on the PokeApiService skeleton, the caching HttpClient wrapper, and the completed PokedexEntry model.
<!-- SECTION:DESCRIPTION:END -->
