## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core/Models, add the wrapper classes for the abilities, past_abilities, game_indices, and held_items arrays of the pokemon payload (https://pokeapi.co/api/v2/pokemon/magnemite), building on the shared Ability, Version, and Item classes from the previous task.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A PokemonAbility class represents entries in the top-level abilities array (IsHidden bool from is_hidden, Slot int, Ability property); the Ability property is nullable so the same class can represent entries in past_abilities[].abilities, where ability can be JSON null
- [x] #2 A PastAbility class represents past_abilities entries (Generation property, Abilities list of PokemonAbility)
- [x] #3 A GameIndex class represents game_indices entries (an int property mapped to "game_index" via [JsonPropertyName], plus a Version property)
- [x] #4 A HeldItem class represents held_items entries (Item property, VersionDetails list)
- [x] #5 An ItemVersionDetail class represents held_items[].version_details entries (Rarity int, Version property)
- [x] #6 Each class lives in its own file in Models per architecture.instructions.md
- [x] #7 Solution builds successfully
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add PokemonAbility.cs, PastAbility.cs, GameIndex.cs, HeldItem.cs, and ItemVersionDetail.cs as separate files in PoorMansPokedex.Core/Models, following the existing file-scoped namespace and one-class-per-file conventions.
2. Map each JSON field explicitly with JsonPropertyName. Give PokemonAbility IsHidden and Slot fields plus a nullable Ability reference; give PastAbility Generation and an Abilities list of PokemonAbility.
3. Model GameIndex.GameIndex as an int mapped to "game_index" with a Version reference. Model HeldItem with Item and a VersionDetails list; model ItemVersionDetail with Rarity and Version. Initialize list properties to empty lists and use nullable reference types only where the payload allows null.
4. Build the solution and perform a focused System.Text.Json deserialization check covering each wrapper and the nullable ability case.
