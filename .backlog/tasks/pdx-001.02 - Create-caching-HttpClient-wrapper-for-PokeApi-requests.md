## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core, create a class that wraps HttpClient to respect PokeApi maintainers' request for well-behaved clients. It wraps HttpClient.GetAsync with basic status-code-based exception handling and a rudimentary in-memory cache keyed by request URI, with an explicit way for callers to bypass the cache and force a fresh call. Assume the HttpClient passed in already has BaseAddress set to https://pokeapi.co/api/v2/. Give it an interface (e.g. IPokeApiHttpClient) alongside the concrete class so it can later be mocked when unit testing PokedexEndpoint.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A new interface and its implementing class exist as separate files (e.g. IPokeApiHttpClient / PokeApiHttpClient), each accepting an HttpClient via its constructor
- [ ] #2 The wrapper exposes an async Get method that wraps HttpClient.GetAsync, checks HttpResponseMessage.StatusCode, and throws or surfaces a clear exception on non-success status codes
- [ ] #3 Repeated calls for the same request URI return the cached HttpResponseMessage (or its content) instead of calling HttpClient.GetAsync again
- [ ] #4 The Get method exposes a parameter (e.g. a bool bypassCache) that, when set, always calls HttpClient.GetAsync and refreshes the cache instead of reading from it
- [ ] #5 Async methods use async/await without ConfigureAwait, per dotnet.instructions.md
- [ ] #6 Solution builds successfully
<!-- AC:END -->
