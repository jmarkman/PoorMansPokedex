## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create the simple, repeated name/url JSON shapes from the magnemite payload as distinct per-context classes in PoorMansPokedex.Core/Models, one class per file: Ability, Species, Item, Move, Stat, Version, VersionGroup, MoveLearnMethod, Generation, and Form (Form already has a worked example in the feature spec: two string autoproperties, Name and Url, mapped with JsonPropertyName to "name" and "url"). Give every other class in this task the identical two-property shape (Name, Url) mapped the same way. These classes are foundational building blocks referenced by nearly every other model subtask in this feature.
