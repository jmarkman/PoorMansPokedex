## Description

Create VersionGroupDetail with LevelLearnedAt (int), VersionGroup (VersionGroup), MoveLearnMethod (MoveLearnMethod), and Order (nullable int), mapped to level_learned_at/version_group/move_learn_method/order. Depends on the Move, VersionGroup, and MoveLearnMethod classes created earlier.
