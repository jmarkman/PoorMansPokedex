## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core/Models, add the wrapper classes for the abilities, past_abilities, game_indices, and held_items arrays of the pokemon payload (https://pokeapi.co/api/v2/pokemon/magnemite), building on the shared Ability, Version, and Item classes from the previous task.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A PokemonAbility class represents entries in the top-level abilities array (IsHidden bool from is_hidden, Slot int, Ability property); the Ability property is nullable so the same class can represent entries in past_abilities[].abilities, where ability can be JSON null
- [ ] #2 A PastAbility class represents past_abilities entries (Generation property, Abilities list of PokemonAbility)
- [ ] #3 A GameIndex class represents game_indices entries (an int property mapped to "game_index" via [JsonPropertyName], plus a Version property)
- [ ] #4 A HeldItem class represents held_items entries (Item property, VersionDetails list)
- [ ] #5 An ItemVersionDetail class represents held_items[].version_details entries (Rarity int, Version property)
- [ ] #6 Each class lives in its own file in Models per architecture.instructions.md
- [ ] #7 Solution builds successfully
<!-- AC:END -->
