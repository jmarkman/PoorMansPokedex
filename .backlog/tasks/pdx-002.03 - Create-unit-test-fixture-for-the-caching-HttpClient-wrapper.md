## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a unit test fixture (NUnit test class) in PoorMansPokedex.Test covering the caching HttpClient wrapper from Feature 1 item 2, using the mocked-HttpMessageHandler helper from MockingTools to control responses and Moq for any other dependency mocking, with Shouldly for all assertions. Cover: (1) common HTTP error status codes (e.g. 404 Not Found, 500 Internal Server Error) being handled explicitly by the wrapper rather than throwing unhandled framework exceptions; (2) a second request for the same path being served from the in-memory cache without the mocked handler recording a second call; (3) a request made with the explicit bypass-cache option making a fresh call to the mocked handler even though a cached value exists for that path, and the cache being updated with the fresh result afterward.
