## Description

Add a unit test fixture (NUnit test class) in PoorMansPokedex.Test covering the caching HttpClient wrapper from Feature 1 item 2, using the mocked-HttpMessageHandler helper from MockingTools to control responses and Moq for any other dependency mocking, with Shouldly for all assertions.
