## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create the PokedexEntry class in PoorMansPokedex.Core/Models as the full deserialization target for GET https://pokeapi.co/api/v2/pokemon/{name|id}. Include every top-level field from the magnemite payload: the primitive fields Id, Name, BaseExperience, Height, IsDefault, Order, Weight, and LocationAreaEncounters (a URL string, mapped to location_area_encounters), plus the nested/collection fields built by the earlier subtasks in this feature: Abilities (List of PokemonAbility), PastAbilities (List of PastAbility), Forms (List of Form), GameIndices (List of GameIndexEntry), HeldItems (List of HeldItem), Moves (List of PokemonMove), Species (Species), Sprites (Sprites), Cries (Cries), Stats (List of StatEntry), PastStats (List of PastStatEntry), Types (List of PokemonTypeSlot), and PastTypes (List of PastType). Every property is mapped via JsonPropertyName to its original JSON name (id, name, base_experience, height, is_default, order, weight, location_area_encounters, abilities, past_abilities, forms, game_indices, held_items, moves, species, sprites, cries, stats, past_stats, types, past_types). This is the capstone subtask for the PokedexEntry model work and depends on every other model subtask in this feature.
