## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core/Models, add the wrapper classes for the stats, past_stats, types, and past_types arrays of the pokemon payload (https://pokeapi.co/api/v2/pokemon/magnemite), building on the shared Stat and ElementType classes from the shared-resources task.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A PokemonStat class represents stats array entries (BaseStat int from base_stat, Effort int, a Stat property); this same class is reused for past_stats[].stats entries
- [ ] #2 A PastStat class represents past_stats entries (a Generation property, a Stats list of PokemonStat)
- [ ] #3 A PokemonTypeSlot class represents types array entries (Slot int, a Type-mapped property typed as ElementType); this same class is reused for past_types[].types entries
- [ ] #4 A PastType class represents past_types entries (a Generation property, a Types list of PokemonTypeSlot)
- [ ] #5 Each class lives in its own file in Models per architecture.instructions.md
- [ ] #6 Solution builds successfully
<!-- AC:END -->
