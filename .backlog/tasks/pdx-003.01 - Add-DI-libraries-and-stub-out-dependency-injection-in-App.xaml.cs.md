## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add the CommunityToolkit.Mvvm and Microsoft.Extensions.DependencyInjection NuGet packages to the PoorMansPokedex WPF project. In App.xaml.cs, build an IServiceProvider during application startup (e.g. overriding OnStartup) that registers an HttpClient (BaseAddress https://pokeapi.co/api/v2/) and PokeApiService/IPokeApiService, plus PokedexViewModel and MainWindow, so dependent classes can resolve PokeApiService through the container instead of newing it up directly. Depends on PokeApiService and IPokeApiService existing from Feature 1.
