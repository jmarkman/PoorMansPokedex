## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Model the "types" and "past_types" arrays from the magnemite payload: {"slot": int, "type": {name,url}}. The nested name/url object under the "type" JSON key must be modeled as a class named ElementalType (per prior decision, to avoid colliding with System.Type) rather than being created in this task. Create PokemonTypeSlot with Slot (int) and Type (ElementalType), mapped to slot/type. Create PastType with Generation (Generation) and Types (List of PokemonTypeSlot), mapped to generation/types. This task includes creating the ElementalType.cs class itself (Name, Url autoproperties mapped to name/url, same shape as the other per-context resource classes), since it was intentionally deferred out of the earlier per-context resource classes subtask due to the naming collision. Depends on the Generation class created earlier.
