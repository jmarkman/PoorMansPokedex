## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In PoorMansPokedex.Core, create a Models folder and add the reusable classes that represent the recurring {"name": "...", "url": "..."} reference objects found throughout the pokemon/{name-or-id} payload (see https://pokeapi.co/api/v2/pokemon/magnemite). Each distinct nested object gets its own class file per architecture.instructions.md, even where shapes are identical, matching the existing Form-class convention: two string autoproperties, Name and Url, each mapped via System.Text.Json.Serialization.JsonPropertyName to "name" and "url". Create Form.cs the same way as the other classes here.
<!-- SECTION:DESCRIPTION:END -->
