## Description

Add three purely aesthetic RowDefinitions to MainWindows Grid: one at the very top, one immediately below it, and one at the very bottom, visually referencing https://archives.bulbagarden.net/media/upload/thumb/3/37/RG_Pok%C3%A9dex.png/730px-RG_Pok%C3%A9dex.png. Second row: an Image control spanning both columns, centered horizontally and vertically, bound to PokedexViewModels image source property, which is populated from the searched PokedexEntrys official artwork front_default sprite URL.
